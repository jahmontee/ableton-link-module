# Remove or recover Poly / Link

Save your patch and remove any installer drive from Hector. In **Poly / View → Module Manager**, select **Ableton Link → Remove**, review saved-preset references, and choose **Restart Hector**. This removes the module and preserves the saved presets and their references. A patch using Link Sync needs the module present to provide its clock output. Network Connection and the shared storage repairs remain installed.

The installer verifies its signature and compatibility before applying it. An interrupted or failed update uses the protected transaction to restore the previous working module state. Save the installer log or the Module Manager message if you need to report a failure.

You can reinstall the same signed release through Poly / View after removal. For an explicit USB reinstall, use Hector’s **Settings → Module Manager → Check ZIP** with the original ZIP on the drive. A USB copy left inserted through normal reboots is processed once.
